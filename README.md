# Babar Hussain

### PhD Researcher in High-Performance Computing · RISC-V RVV/IME · GEMM Optimization

I am a PhD researcher at the University of Salerno, Italy, working on efficient numerical kernels and reproducible performance evaluation for RISC-V systems. My current research connects low-level implementation, compiler behavior, and microarchitectural performance.

## Current PhD research

**High-Performance Computing for RISC-V Architectures**

- RVV and SpacemiT IME microkernels for INT8 GEMM
- Tiling, loop ordering, vector-length behavior, and register pressure
- Compiler-aware optimization and generated-code analysis
- Reproducible benchmarking, performance counters, and correctness validation

## Previous Master's research

**Anomaly Detection of Industrial IoT Using Deep Learning Autoencoders**

My Master's research focused on reconstruction-based anomaly detection using recurrent neural networks and autoencoders for industrial data.
