## Research profile

I am a PhD researcher at the University of Salerno, Italy, studying efficient numerical kernels and performance evaluation for RISC-V architectures. My work connects low-level implementation, compiler behavior, microarchitectural analysis, and reproducible experimentation.

<table>
<tr>
<td width="50%" valign="top">

### Current PhD research

**High-Performance Computing for RISC-V Architectures**

- RVV and SpacemiT IME microkernels for INT8 GEMM
- Tiling, loop ordering, vector-length behavior, and register pressure
- Compiler-aware optimization and generated-code analysis
- Benchmarking, performance counters, and correctness validation

</td>
<td width="50%" valign="top">

### Previous Master's research

**Anomaly Detection of Industrial IoT Using Deep Learning Autoencoders**

Reconstruction-based anomaly detection using recurrent neural networks and autoencoders for industrial data.
